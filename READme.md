# ИИ-агент «Помощник по тренировкам»

**Назначение агента:** Помогать 
пользователю планировать и отслеживать 
физические тренировки, вести историю 
результатов и получать рекомендации.

**Язык программирования:** Python

## Планируемые возможности

*   **Добавление тренировок:**
*   Сохранение информации о дате, типе
*   тренировки и её длительности.
*   **Запись результатов:** Внесение
*   данных о выполненных упражнениях
*   (подходы, повторения, вес).
*   **Просмотр истории:** Отображение
*   списка всех тренировок за выбранный
*   период.
*   **Статистика:** Подсчёт общего
*   количества тренировок и времени,
*   проведённого в зале, за неделю или
*   месяц.
## Примеры запросов и ожидаемые результаты

**Запрос 1:** «Добавь тренировку по бегу, которая была вчера, длилась 45 минут».

**Ожидаемый результат:** Агент создаёт новую запись в истории тренировок с типом «бег», датой «вчера» и длительностью 45 минут. Пользователь видит подтверждение: `Тренировка по бегу добавлена.`

---

**Запрос 2:** «Покажи мои тренировки за последнюю неделю».

**Ожидаемый результат:** Агент выводит список всех тренировок, которые были сохранены за последние 7 дней, в виде:
*   `2026-10-15: Бег, 45 мин.`
*   `2026-10-17: Силовая тренировка, 60 мин.`
