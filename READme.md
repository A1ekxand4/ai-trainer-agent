# ИИ-агент «Помощник по тренировкам»

**Назначение агента:** Помогать 
пользователю планировать и отслеживать 
физические тренировки, вести историю 
результатов и получать рекомендации.

**Язык программирования:** Python

## Планируемые возможности

*   **Добавление тренировок:**
*   Сохранение информации о дате, типе
*   тренировки и её длительности.
*   **Запись результатов:** Внесение
*   данных о выполненных упражнениях
*   (подходы, повторения, вес).
*   **Просмотр истории:** Отображение
*   списка всех тренировок за выбранный
*   период.
*   **Статистика:** Подсчёт общего
*   количества тренировок и времени,
*   проведённого в зале, за неделю или
*   месяц.

## Технологический стек (Лабораторная №2)
* **Язык:** Python 3.10+
* **Менеджер зависимостей:** pip (`requirements.txt`)
* **Библиотека для вывода:** `rich`
* **Линтер и форматтер:** `ruff`
* **Отладчик:** Встроенный в VS Code (Python Debugger)
* **Хранение данных:** В памяти (список `TRAININGS` в `src/tasks.py`). После перезапуска сбрасывается.

## Установка и запуск
1. Установите зависимости:
   `pip install -r requirements.txt`
2. Запустите приложение:
   `python main.py`

## Команды приложения
* `add <тип> <минуты>` — добавить тренировку
* `list` — показать все тренировки
* `stats` — показать статистику
* `help` — справка
* `exit` — выход

## Проверка качества кода и обработка ошибок

**Инструменты:**
* Линтер и форматтер: **Ruff**.

**Как воспроизвести проверки:**
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите линтер: `ruff check .` (ожидаемый результат: `All checks passed!`)
3. Запустите форматтер: `ruff format .`

**Обработка ошибок ввода:**
В приложении реализована обработка следующих ошибочных ситуаций:
* Ввод несуществующей команды (выводится подсказка).
* Неверное количество аргументов для команды `add` (например, `add бег`).
* Ввод нечислового значения для длительности (например, `add бег много`).
* Ввод отрицательного числа для длительности.
* Штатное завершение по `Ctrl+C` (не вызывает падения программы).
* Перехват любых непредвиденных исключений (программа не вылетает с ошибкой).
